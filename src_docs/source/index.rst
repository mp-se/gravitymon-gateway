GravityMon Gateway Documentation
################################

Welcome to the documentation for **GravityMon Gateway**, a networked companion
for GravityMon and PressureMon devices. The gateway receives measurements over
Bluetooth Low Energy (BLE) or Wi-Fi, presents current device data, and forwards
measurements to configured services.

This documentation covers the gateway firmware and supported gateway hardware.
For GravityMon and PressureMon device documentation and firmware flashing,
visit the `GravityMon website <https://www.gravitymon.com>`_ and its
`Web Flasher <https://www.gravitymon.com/flasher/index.html>`_.

.. tip::

   New to the gateway? Start with :doc:`installation`, then follow
   :doc:`configuration` to connect it to your network and configure data
   forwarding.
