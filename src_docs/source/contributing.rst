Contributing
############

Contributions are welcome. Before opening a change, describe the board or
device involved and the behavior being changed. Keep board-specific code
guarded so builds for other gateway targets remain usable.

Build the affected PlatformIO environments and review generated firmware or
web assets before submitting. Do not commit secrets, Wi-Fi credentials, or
device specific configuration exports.

Open issues and pull requests in the `GravityMon Gateway repository
<https://github.com/mp-se/gravitymon-gateway>`_.
